# 低轨卫星网络典型路由算法复现与性能对比

本项目用于完成智能通信网络课程作业。目标是在纯软件环境中建立一个 36 至 64 节点的简化低轨卫星网络，比较基于传播时延的最短路径、综合传播时延与队列状态的加权路径，以及简化交通灯路由，并形成可复现、可检查的代码、数据、图表和课程报告。

## 必须完成的实验

- 建立 6 个轨道面、每面 6 颗卫星，共 36 个节点的固定拓扑；轨道内和相邻轨道之间有双向星间链路。
- 生成均匀业务和热点业务两类流量，模拟有限队列、分组转发、排队与丢弃。
- 实现 `dijkstra_delay`、`queue_weighted`、`traffic_light` 三种路由基线。
- 在至少 3 档负载和 2 类业务下，每档独立运行不少于 5 个随机种子。
- 统计平均端到端时延、分组交付率、有效吞吐量和链路负载分布。
- 交付不少于 6 篇参考文献、可运行代码、基础实验数据和说明、结果图、不少于 3000 字的报告。

作业原文的整理稿和逐项验收要求见 [课程作业要求](docs/课程作业要求.md)，统一实验规则见 [实验规范](docs/实验规范.md)。

## 开发约定

建议使用 Python 3.11 或更高版本。每位成员在独立分支修改所负责的模块，通过 Pull Request 合入 `main`。实验脚本必须接受固定随机种子，并输出可直接用于图表生成的 CSV 或 JSON。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest
```

基础配置位于 `configs/base.yaml`。实现完成后，基础实验应可由一条命令启动，最终命令和输出位置由实验负责人写入 [实验规范](docs/实验规范.md)。

## 核心验收标准

1. 任意成员在新机器上按 README 安装后，能运行同一份基础实验。
2. 三种算法使用相同拓扑、流量、负载、仿真时长和随机种子。
3. 每次实验记录随机种子、参数、代码提交号和结果摘要。
4. 报告中每个结论都能追溯到图表、实验数据或参考文献。
5. 所有 AI 辅助生成或修改的代码、文字和结果解释都经过人工检查和测试，并记录在 [AI 使用记录](docs/AI使用记录.md)。
